# Mist Map

걸은 만큼 안개가 걷히는 손그림 지도의 웹 프로토타입입니다. 목표는 안개 표현의 "느낌"을 먼저 확정하는 것이고, 마음에 드는 모습이 나오면 같은 셰이더 구조를 모바일 앱으로 옮길 계획입니다.

## 실행

ES 모듈을 쓰므로 정적 서버가 필요합니다.

```bash
python -m http.server 5174
```

브라우저에서 `http://localhost:5174` 를 엽니다. WebGL2와 float 렌더 타깃을 지원하는 브라우저가 필요합니다.

- `W A S D` / 방향키로 걷기, `Shift`를 누르면 달리기
- 지도를 클릭하면 그 지점까지 걸어감
- 산책: 자동으로 돌아다님 · 내 위치: 실제 GPS를 따라감 · 초기화: 기록 삭제
- 기록은 이 브라우저의 `localStorage`에만 저장됨
- `?debug` 를 붙이면 콘솔에서 `window.__mist` 로 시뮬레이션을 돌릴 수 있음

## 구조

| 파일 | 역할 |
| --- | --- |
| `src/mapStyle.js` | OpenFreeMap 벡터 타일로 그린 종이·잉크 팔레트 지도 스타일 |
| `src/fog.js` | 안개 커스텀 레이어 (WebGL2, 2패스) |
| `src/main.js` | 캐릭터 이동, 밝히기, 저장, HUD |

### 안개 렌더링

1. 밝힌 지점마다 가우시안 블롭을 float 텍스처에 더해 "밝음 필드"를 만듭니다.
2. 필드로 경계까지의 거리를 추정한 뒤, 안쪽은 지도를 보여 주고 바깥쪽은 종이를 그립니다. 경계는 잉크선, 그 바깥은 점점 넓어지는 등고선 링, 더 멀리는 노이즈로 만든 지형 등고선이 깔립니다.
3. 새 지점의 반경을 스프링 곡선으로 키우면 링들이 물결처럼 밀려나며 안개가 걷힙니다.
